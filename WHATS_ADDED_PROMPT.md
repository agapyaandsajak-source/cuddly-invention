## About Custom Nether, End & Structures

✅ **Configurable in `config.yml`:**
```yaml
custom-worlds:
  nether:
    enabled: true
  end:
    enabled: true
  structures:
    enabled: true
```

These are feature flags ready for world generation plugins or datapacks to hook into. The plugin provides the toggle infrastructure - pair with:
- **Custom Nether:** Nether custom generation plugin/datapack
- **Custom End:** End dimension custom generator
- **Custom Structures:** Structure generation mod/datapack
